# Team photos

Drop real photographs here. They are picked up automatically at build time:

| File name (jpg, jpeg, png, webp or avif) | Used for                                      |
| ---------------------------------------- | --------------------------------------------- |
| `amir-ali.jpg`                           | Founder portrait in the About section         |
| `horticulturist.jpg`                     | Team card (optional)                          |
| `architect.jpg`                          | Team card (optional)                          |
| `nurserymen.jpg`                         | Team card (optional)                          |

Until a photo is added, the layout shows an illustrated placeholder. Portrait photos work best at
about 1000 × 1250 px (4:5). Use photos of the real people only.
